# 📋 My Attendance Tracker

A simple, fully offline PWA for tracking class attendance using the Persian (Jalali) calendar. No server, no account — all data stays on your device.

## Usage

1. Open `index.html` in a browser, or visit the GitHub Pages URL.
2. Click **➕ Add Course** to create a course.
3. Click a course card, pick a date, and mark **Present**, **Late**, **Absent**, or **Excused**.
4. Add notes per course or per session.
5. Use **💾 Backup** to export JSON/CSV or restore from a file.

> **Note:** Data is stored in your browser's `localStorage`. Always keep a backup — clearing browser data will erase everything.

### Install as PWA
Visit the hosted URL over HTTPS and click **📲 Install app** in the header.
